# LinOS MCP 工具箱（浏览器扩展）

在**网页版 AI**（DeepSeek / Gemini / 千问）里直接调用本机 MCP 工具。

## 它解决什么

网页版 AI 本身没有"调用外部工具"的能力，扩展在页面右下角加一个浮层：
你点「列出工具」→ 选工具 → 填参数 → 执行 → 把结果复制回对话。
不需要 API Key，用的是网页登录态 + 本机 MCP。

## 安装（Chrome，2 分钟）

1. 打开 `chrome://extensions/`
2. 右上角打开「开发者模式」
3. 点「加载已解压的扩展程序」→ 选择本目录（`extension/`）
4. 打开 https://chat.deepseek.com ，右下角应出现 **MCP** 圆形按钮

Edge：`edge://extensions/` → 同样打开「开发人员模式」→「加载解压缩的扩展」。
（Chrome 主用、Edge 兜底，两者都兼容 MV3。）

## 首次配置

1. 控制中心「设置 → 其他 AI 客户端」→ 点「生成令牌」→ 复制 `c2c_api_...`
2. 点扩展面板的 **⚙**：
   - 地址：`http://127.0.0.1:48766/mcp`（默认端口）；跨网络用 `https://mcp.example.com/mcp`
   - 令牌：粘贴刚才复制的
3. 点「保存」

## 使用

1. 点 **列出工具**（应显示 74–90 个）
2. 选工具，例如 `read_file`，参数填 `{"path":"C:\workspace\\README.md"}`
3. 点「执行」→ 结果出现在下方
4. 点「复制结果」→ 粘回 DeepSeek 对话

## 安全

- 令牌只存在浏览器本地（`chrome.storage.local`），不上传任何第三方；
- 扩展只对 `127.0.0.1` 与两条隧道域名发请求；
- 不再使用时：控制中心「撤销令牌」即可让扩展立即失效；
- 建议把 `delete_file` / `apply_patch` / `start_job` 设为"需确认"，避免误删。

## 已知限制（MVP）

- 需要手动"列出工具 → 选 → 填参数"，还不是"AI 自动调"；
- 页面改版可能影响浮层位置（功能不受影响，面板是 Shadow DOM 隔离的）；
- 暂未做：一键把当前对话里提到的问题转成工具调用（下一步）。
